Visão geral

O Dev Automation Kit é apresentado como um aplicativo desktop para preparar contexto para IA e investigar bases de código. Esta página documenta a vitrine web e sua demonstração interativa.

O código do aplicativo desktop não está neste repositório. Detalhes de implementação e disponibilidade dos recursos precisam ser confirmados na fonte do aplicativo.

Este site e o aplicativo

Este repositório contém páginas estáticas em HTML, CSS e JavaScript. O mockup da página inicial é uma simulação: suas contagens e resultados são ilustrativos e não analisam arquivos reais.

Execução local do site
python3 -m http.server 8080

Abra http://localhost:8080 no navegador.

Preparação de contexto

Na demonstração, marque arquivos na árvore para alterar os indicadores e use “Gerar” para simular a criação de contexto. A contagem de tokens exibida é uma estimativa ilustrativa, não uma medição do seu projeto.

Antes de compartilhar contexto com um serviço de IA, revise o conteúdo e remova informações que não deseja enviar.

Diagnósticos

A aba Diagnósticos apresenta exemplos de verificações de código. Os resultados mostrados são ilustrativos; a demonstração não executa uma análise.

As descrições do site mencionam clones, auditoria JS/TS, configurações e dependências. Os critérios e a disponibilidade dessas verificações devem ser confirmados no aplicativo.

Configuração

O site não requer instalação ou compilação. Tailwind CSS, Lucide e fontes são carregados de serviços externos; o formulário envia dados ao Formspree. Uma conexão é necessária para esses recursos.

Bateria de diagnósticos

A página inicial apresenta uma bateria de verificações como recurso do aplicativo. Consulte a documentação do aplicativo para conhecer os diagnósticos disponíveis, suas entradas e seus resultados.

Temas

Na seção Temas, selecione Dark Glass, Aero ou Cyberpunk para alterar a prévia. A seleção modifica apenas a demonstração no navegador.

Licença e distribuição

Não há arquivo de licença neste repositório. Verifique a licença e os termos de distribuição na fonte oficial do projeto antes de redistribuir o código ou o aplicativo.

Site e contato

As opções de download abrem um modal com apoio opcional via Pix. O fluxo atual cria um arquivo .info.txt, não um instalador. O formulário de contato envia as informações preenchidas ao Formspree.

Para dúvidas sobre este site, consulte o repositório web.
